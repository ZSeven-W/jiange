# 功能一览

Jiange 是一套开源、可私有化部署、AI 原生的全栈协作套件（完整多语种介绍见根目录 [README.md](../README.md)）。

## 云文档（Cloud Doc）
- **自研块编辑器与 CRDT 协同**：基于 RGA/Fugue 序列 CRDT + Peritext marks，实时光标与选区感知，支持 IndexedDB 深度离线编辑与重连自动合并。
- **15+ 富媒体与互动块**：标题（H1–H9）、列表、待办、折叠列表、引用、高亮块、代码块（语法高亮与复制）、表格块、多栏布局、同步块、子页面列表、公式（KaTeX）、Mermaid 图表、流程图/白板、日期提醒、原生音频/视频、实时投票（Poll）、倒计时（Countdown）、标签页（Tabs）、嵌入式电子表格/多维表格/问卷/幻灯片。
- **审阅与版本**：行内修订模式（Track Changes）、划词批注与表情回应、@成员补全与通知中心、跟随阅读、手动/自动历史版本与差异对比。
- **导入导出与分享**：DOCX / Markdown（含图片）双向导入导出、PDF 打印、三级权限继承、公开/密码分享、防复制下载与全套件水印。

## 电子表格（Sheet）
- **WebGPU/WebGL2 百万行虚拟网格**与 Fenwick 树变高滚动，零 Canvas 2D 依赖。
- **148 个内置公式函数**：含 `XLOOKUP`、`FILTER`、`SORT`、`UNIQUE`、`LET`、`LAMBDA`、`ARRAYFORMULA`、`QUERY`、`REGEX*`、`IMAGE` 等，AST + DAG 增量重算。
- **分析与协作**：浮动图表、数据透视表、行内 SVG 迷你图（Sparklines）、行列分组折叠、单元格图片、条件格式/数据校验/保护区域、云端命名区域、单元格变更历史与版本回滚、离线单元格增量合并、XLSX/CSV 双向导入导出、表格 AI 公式助手。

## 多维表格（Base）
- **多表与双向关联**：支持 **23 种字段类型**（文本、数字、货币、进度、自动编号、动作按钮、地理位置、单选/多选、复选框、日期、人员、附件、URL/电话/邮箱、评分、创建人/修改人/时间、公式、双向关联、查找引用）。
- **7 种视图**：网格、看板、甘特图（含前置依赖连线）、日历、画册、层级树视图、带条件分支的公开收集表单。
- **治理与自动化**：最多 3 级嵌套分组、多步自动化工作流、数据仪表盘、细粒度行/列级 RBAC 与视图锁定、XLSX/CSV 导入导出、AI 按列批量填充。

## 幻灯片（Slides）
- WebGPU/WebGL2 画布、母版与品牌套件（Master Brand Kit）、文本/形状/表格/图表/视频/音频元素与图片裁剪。
- 元素逐项动画与页面切换、演讲者模式（激光笔/画笔批注 + 基于 WebSocket 的观众实时跟随放映）、页/元素评论、历史版本、离线草稿合并、PPTX 双向导入导出与 PDF 打印。

## 画板与思维导图（Board & MindMap）
- 无限画布、流程图与泳道、便签/荧光笔/圆点投票/倒计时/小地图/分组框架。
- 多结构思维导图、外框/概要/徽章、与大纲双向同步、AI 生成流程图、Mermaid / XMind / draw.io / SVG / PNG 导出。

## 知识库、云盘、搜索与 AI 工作区
- **多工作空间全生命周期**：创建、一键切换、重命名、所有权转让（UI + API）、成员退出与删除；独立知识库空间（Wiki）、快捷方式与跨空间移动。
- **全格式预览与存储配额**：图片/PDF/音视频/代码/Markdown/CSV/Office（`.docx`/`.xlsx`/`.pptx`）在线预览、空间存储用量看板与配额拦截（HTTP 413）。
- **纯 Go 附件全文抽取 + OCR + 混合 RAG**：PDF/DOCX/XLSX/PPTX/文本代码自动入库，支持可插拔 OCR（HTTP / OpenAI Vision / `tesseract`）与 CLI/UI 存量回填；全空间混合向量 + BM25 RAG 问答与单文档 AI 均支持 SSE 逐字流式输出。

## 企业身份安全、治理与云原生运维
- **Enterprise IAM**：OIDC / OAuth2 + SAML 2.0 SP、完整 SCIM 2.0（RFC 7644）、LDAP v3 / 企业微信 / 钉钉主动拉取与定时同步、TOTP MFA + 8 组恢复码 + 空间强制 MFA 策略与全局顶部横幅、WebAuthn / Passkeys（FIDO2 ES256/RS256）无密码登录。
- **账号安全自助与防爆破**：登录/注册/MFA/Passkey/重置密码/公开链接密码限流、修改密码、SMTP 忘记/重置密码、活跃登录设备列表与远程踢出。
- **安全合规与开放生态**：企业 DLP（关键词 + 安全 RE2 正则，拦截公开分享与导出）、数据保留周期策略与自动/手动清扫、全套件防泄密水印、安全审计日志与 CSV 导出、361 接口 100% 校验的 OpenAPI 3.1.0 契约与开发者门户、PAT 个人访问令牌、全 6 类空间事件 HMAC-SHA256 Webhook、外部通知渠道（SMTP/飞书/钉钉/企微/Slack）。
- **多副本高可用与国际化**：4 大实时协同 Hub 全部基于 Postgres `LISTEN/NOTIFY` 水平扩展；全仓中/英双语完整国际化（5,332 条词条）与 9 语种 README；路由级分包（主包 308 KB / gzip 84 KB）；`/healthz` + `/readyz` + Prometheus `/metrics` + W3C `traceparent`；SHA-256 备份恢复 CLI、Helm Chart 与 Kustomize 清单。
