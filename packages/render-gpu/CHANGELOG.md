# Changelog — @zseven-w/render-gpu

## [0.2.0] - 2026-11-21

### Added & Changed
- Initial release of zero-dependency WebGPU (primary) -> WebGL2 (fallback) -> Headless GPU rendering engine with zero Canvas 2D usage.
- Includes instanced SDF Rect, Line, Arc, and procedural Bitmap Glyph Atlas pipelines, sparse `FenwickVirtualizer`, `VirtualList1D`, `VirtualGrid2D`, and `SpatialIndex`.
- Achieved 100% V8 unit test coverage.
