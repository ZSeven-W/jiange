# Headless TypeScript SDKs 参考指南（L0 / L1 全 7 包）

所有 L0/L1 包均为纯 ES2022 TypeScript 编译的 ESM 包（附带 `NodeNext` 类型声明与 `"sideEffects": false`），零浏览器 DOM 依赖，可运行于 Node.js 18+、Cloudflare Workers / Deno / Bun、Web Workers 及现代浏览器。

## 1. `@zseven-w/ooxml` — 零依赖 ZIP 与有界 XML 基础库

- **安装**：`npm install @zseven-w/ooxml`（0 依赖，4.9 KB gzip）
- **子路径**：`.`、`./zip`、`./xml`

### 核心 API

| 模块 | 导出符号 | 说明 |
| --- | --- | --- |
| `./zip` | `createZip(entries, modified?)` | 同步生成 STORE 格式 ZIP（零异步开销） |
| `./zip` | `createZipAsync(entries, options?)` | 异步 raw DEFLATE 压缩（原生 `CompressionStream("deflate-raw")`，压缩后更大或环境不支持时自动回退 STORE） |
| `./zip` | `listZip(bytes, options?)` / `readZipEntry(bytes, entry, limit)` | 列出条目并按调用方指定解压字节上限安全解压，自动校验 CRC-32 与 `ZIP_DEFAULT_MAX_ENTRIES` (`10_000`) |
| `./zip` | `deflateRaw` / `inflateRaw` / `crc32` / `ZipError` | 底层压缩/解压流与 CRC-32 工具 |
| `./xml` | `parseXml(source, { maxNodes? })` / `XmlError` | 拒绝 `<!DOCTYPE`（防 XXE / Billion Laughs）的有界 XML 解析器 |
| `./xml` | `child(el, name)` / `children(el, name?)` / `textContent(el)` / `escapeXml(text)` | 轻量 XML 节点遍历与安全转义 |

```ts
import { createZipAsync, listZip, readZipEntry, parseXml, child, textContent } from "@zseven-w/ooxml";

const zip = await createZipAsync([
  { name: "doc.xml", data: new TextEncoder().encode("<root><item>OK</item></root>") },
]);
const [entry] = listZip(zip);
const bytes = await readZipEntry(zip, entry, 1024 * 1024);
const xml = parseXml(new TextDecoder().decode(bytes), { maxNodes: 5000 });
console.log(textContent(child(xml, "item")!)); // "OK"
```

## 2. `@zseven-w/collab` — CRDT 协同内核与可选适配器

- **安装**：`npm install @zseven-w/collab`（0 依赖，35.1 KB gzip）
- **子路径**：`.`、`./table`、`./ws`、`./storage`、`./ai-agent`

### 2.1 主入口 `@zseven-w/collab`

- **文档 CRDT**：`Doc`（RGA/Fugue 文本序列 + 块树 LWW/move + Peritext 富文本 marks）、`Tx`（批量事务）、`ROOT`、`OpId`、`idKey` / `parseKey` / `cmpId` / `eqId`、`keyBetween`（Fractional Indexing）。
- **二进制线协议**：`encodeOps` / `decodeOps`、`encodeClientMsg` / `decodeClientMsg`、`encodeServerMsg` / `decodeServerMsg`（与 Go 端 `server/collab` 通过 `spec/vectors` 逐字节一致）。
- **状态同步与历史**：`SyncClient`（传输无关状态机）、`UndoManager`（支持异步插入点 `markInsertionPoint` / `insertMarkerAt`）。

### 2.2 表格 CRDT 子路径 `@zseven-w/collab/table`

提供 `CollabTable`（`ExperimentalTable` 稳定别名）、Lamport ID 分配器 `TableIdAllocator` 以及紧凑二进制 `ttable` 帧编解码 `encodeTableOps` / `decodeTableOps`：

```ts
import { Doc } from "@zseven-w/collab";
import { CollabTable, TableIdAllocator, encodeTableOps, decodeTableOps } from "@zseven-w/collab/table";

const doc = new Doc(1);
const alloc = new TableIdAllocator(1, doc);
const table = new CollabTable();
const id = alloc.next();
const payload = encodeTableOps([]);
const decoded = decodeTableOps(payload);
void [table, id, decoded];
```

### 2.3 WebSocket 同步适配器 `@zseven-w/collab/ws`

`WebSocketSyncAdapter` 内置指数退避重连（`reconnectBaseMs` / `reconnectMaxMs` / `maxRetries`）、定时心跳（`heartbeatIntervalMs` / `heartbeatPayload`）与断网自动排队重发（`queuedCount`）：

```ts
import { WebSocketSyncAdapter } from "@zseven-w/collab/ws";

const adapter = new WebSocketSyncAdapter({
  url: "wss://sync.example.com/rooms/doc-42",
  reconnectBaseMs: 500,
  reconnectMaxMs: 15_000,
  heartbeatIntervalMs: 20_000,
  onStateChange: (state) => console.log("WS:", state),
  onMessage: (frame) => console.log("Received:", frame),
});
adapter.connect();
```

### 2.4 离线草稿存储 `@zseven-w/collab/storage`

统一 `DraftStorageAdapter` 接口，内置 `MemoryDraftStorage`（Node/Edge/单测）与零依赖浏览器 `IndexedDbDraftStorage`：

```ts
import { Doc } from "@zseven-w/collab";
import { MemoryDraftStorage, IndexedDbDraftStorage } from "@zseven-w/collab/storage";

const storage = typeof indexedDB !== "undefined"
  ? new IndexedDbDraftStorage({ dbName: "my-app-drafts" })
  : new MemoryDraftStorage();

const doc = new Doc(1);
await storage.save({
  docKey: "doc-42",
  snapshot: doc.saveState(),
  pendingOps: [],
  updatedAt: Date.now(),
});
```

### 2.5 AI 协作者会话 `@zseven-w/collab/ai-agent`

`AiCollabSession` 让 AI Agent 以独立 `clientId` 与实时在场状态（`idle` | `thinking` | `editing`）加入协同文档，每次编辑产出标准 `Op[]` 与二进制 `encoded` 帧：

```ts
import { AiCollabSession } from "@zseven-w/collab/ai-agent";

const ai = new AiCollabSession({
  agentId: "assistant-1",
  agentName: "Jiange AI",
  clientId: 9001,
  onAwareness: (a) => console.log("Presence:", a.status, a.message),
  onEmitOps: (_ops, encoded) => console.log("Broadcast bytes:", encoded.byteLength),
});

ai.setPresence("thinking", undefined, "Summarizing Q4 metrics...");
const { blockId } = ai.appendParagraph("Q4 summary generated by AI.");
void blockId;
```

## 3. `@zseven-w/sheet-sdk` — 电子表格与 148 函数增量公式引擎

- **安装**：`npm install @zseven-w/sheet-sdk`（仅依赖 `@zseven-w/ooxml`，72.6 KB gzip）
- **常用子路径**：`.`、`./workbook`、`./ai-tools`、`./formula-engine`、`./formula-functions`、`./formula-ast`、`./worker`、`./xlsx`、`./xlsx-read`、`./workbook-xlsx`、`./csv`、`./tsv`、`./numfmt`、`./rules`、`./analytics`、`./collab`

### 3.1 `Workbook` & `WorksheetProxy`

- **构造工厂**：`Workbook.create(options?)`、`Workbook.fromXlsx(bytes, options?)`、`Workbook.fromCsv(csv, sheetName?)`、`Workbook.fromTsv(tsv, sheetName?)`、`Workbook.fromSnapshot(sheets, definedNames?)`。
- **工作表操作**：`listSheets()`、`sheet(nameOrIndex)`、`addSheet(name, rows?, cols?)`、`renameSheet(oldName, newName)`、`deleteSheet(name)`。
- **单元格与结构 (`WorksheetProxy`)**：`getCell(a1)`、`getValue(a1)`、`getFormatted(a1)`、`setCell(a1, raw, style?)`、`getRange(rangeA1)`、`setRange`（via `apply` / proxy）、`clearRange`、`merge` / `unmerge`、`setFreeze(rows, cols)`、`setColWidth` / `setRowHeight`、`sort(col, asc?, headerRow?)`、`addValidation`、`addConditionalFormat`、`addChart`、`addPivotTable`、`addHyperlink`、`addComment`。
- **导出与历史**：`toXlsx()`、`toXlsxAsync()`（DEFLATE + `sharedStrings.xml`）、`toCsv(sheetName?)`、`toTsv(sheetName?)`、`toSnapshot()`、`undo(token?)` / `redo()`。
- **AI 原语**：`inspect(options?)`、`query(params?)`、`apply(ops, options?)`、`verify()`、`createSheetTools(wb)`。

### 3.2 AST + DAG 增量公式引擎（148 个内置函数）

`SUPPORTED_FORMULA_FUNCTIONS` 共内置 **144** 个高频函数，支持整列/整行引用（`A:A`、`1:1`）、命名区域（`wb.defineName`）、自定义函数（`wb.registerFunction`）、双向溯源（`wb.getPrecedents` / `wb.getDependents`）、动态数组（`FILTER`、`SORT`、`SORTBY`、`UNIQUE`、`SEQUENCE`）与 `#SPILL!` / `#CYCLE!` 诊断：

```ts
import { Workbook, SUPPORTED_FORMULA_FUNCTIONS } from "@zseven-w/sheet-sdk";

const wb = Workbook.create({ sheets: [{ name: "Calc" }] });
wb.defineName("TAX_RATE", "0.08");
wb.registerFunction("DOUBLE_PLUS", (args) => Number(args[0]?.value ?? 0) * 2 + 1);

const sh = wb.sheet("Calc");
sh.setCell("A1", 100);
sh.setCell("B1", "=A1*(1+TAX_RATE)");
sh.setCell("C1", "=DOUBLE_PLUS(A1)");
console.log(sh.getValue("B1"), sh.getValue("C1"), SUPPORTED_FORMULA_FUNCTIONS.length);
// 108, 201, 144
```

### 3.3 零依赖 Web Worker 异步公式协议 (`@zseven-w/sheet-sdk/worker`)

`createFormulaWorkerHost()` 与 `FormulaWorkerClient` 基于最小 `MessagePortLike` 接口，适用于浏览器 Web Worker、Node.js `worker_threads` 或 `MessageChannel`：

```ts
import { createFormulaWorkerHost, FormulaWorkerClient, type FormulaWorkerRequest } from "@zseven-w/sheet-sdk/worker";

// Worker 侧
const handle = createFormulaWorkerHost();
// self.onmessage = (e) => self.postMessage(handle(e.data as FormulaWorkerRequest));

// 主线程侧（示例通过自定义 MessagePortLike）
const channel = new MessageChannel();
channel.port2.onmessage = (e) => channel.port2.postMessage(handle(e.data as FormulaWorkerRequest));
const client = new FormulaWorkerClient(channel.port1);
await client.load(wb.toSnapshot().sheets, wb.toSnapshot().definedNames);
const patch = await client.update(1, [{ row: 0, col: 0, raw: "250" }]);
client.dispose();
void patch;
```

### 3.4 声明式 `WorkbookOp` 批操作

`wb.apply(ops, { dryRun })` 支持 15 种声明式操作：`setCells`、`setRange`、`clearRange`、`addSheet`、`renameSheet`、`deleteSheet`、`merge`、`unmerge`、`setFreeze`、`resize`、`sort`、`defineName`、`addValidation`、`addConditionalFormat`、`addChart`。

## 4. `@zseven-w/doc-sdk` — 块文档、Markdown/HTML/DOCX 与修订批注

- **安装**：`npm install @zseven-w/doc-sdk`（依赖 `@zseven-w/collab`、`@zseven-w/ooxml`；已彻底解耦 `@zseven-w/whiteboard-sdk`；58.1 KB gzip）
- **常用子路径**：`.`、`./document`、`./ai-tools`、`./markdown`、`./html`、`./docx`、`./model`、`./table-cells`、`./block-styles`、`./column-widths`、`./column-move`、`./column-archive-experimental`

### 核心能力与示例

- **4 格式构造与导出**：`Document.create` / `fromMarkdown` / `fromHtml` / `fromDocx` / `fromCollabDoc` ↔ `toMarkdown` / `toHtml` / `toPlainText` / `toDocx` / `toDocxAsync`（DEFLATE）。
- **结构导航与安全替换**：`outline()`、`readSection(headingOrId)`、`replaceText(search, replacement, { caseSensitive, skipCodeAndMath })`（保留字符级格式标记）。
- **修订建议与批注**：`addSuggestion` / `acceptSuggestion` / `rejectSuggestion` / `listSuggestions`、`addComment` / `replyComment` / `resolveComment` / `listComments`。
- **DOCX 保真诊断**：`docxExportLosses(view)`、`parseDocx` / `buildDocx` / `buildDocxAsync`（支持 H1–H9、合并单元格表格、嵌入图片、批注、脚注与页眉页脚）。

```ts
import { Document, createDocTools } from "@zseven-w/doc-sdk";

const doc = Document.fromMarkdown(
  "# RFC\n\n## Goals\n\nShip lightweight SDKs.\n\n## Non-Goals\n\nAvoid heavy runtimes.\n",
  "RFC",
);

const section = doc.readSection("Goals");
const suggestion = doc.addSuggestion({
  blockId: section!.blocks[1].id,
  op: "replace",
  text: "Ship ultra-lightweight AI-native SDKs.",
  author: "AI Reviewer",
});
doc.acceptSuggestion(suggestion.id);

const comment = doc.addComment({
  blockId: section!.blocks[1].id,
  body: "Approved for v0.2.0 release.",
  author: "Lead",
});
doc.resolveComment(comment.id, true);

const docx = await doc.toDocxAsync({ title: doc.title });
const tools = createDocTools(doc);
console.log(doc.verify(), docx.byteLength, tools.tools.length); // [], >0, 7
```

## 7. `@zseven-w/base-sdk` — 零依赖多维表格引擎

- **安装**：`npm install @zseven-w/base-sdk`（**0 运行时依赖**，14.7 KB gzip）
- **常用子路径**：`.`、`./base`、`./ai-tools`、`./types`、`./formula`、`./query`、`./dashboard`、`./csv`

### 7.1 18 种内置字段类型（`FieldType`）

`text`、`number`、`select`、`checkbox`、`date`、`multi_select`、`person`、`attachment`、`created_by`、`created_at`、`modified_at`、`url`、`phone`、`email`、`rating`、`formula`、`link`、`lookup`。

### 7.2 拓扑 `[Field]` 公式引擎（35 函数）、视图查询与仪表盘

- **35 个内置公式函数 (`FUNCS`)**：`ABS`, `AND`, `AVERAGE`, `BLANK`, `CEILING`, `CONCATENATE`, `CONTAINS`, `DAY`, `FLOOR`, `IF`, `IFS`, `INT`, `ISBLANK`, `LEFT`, `LEN`, `LOWER`, `MAX`, `MID`, `MIN`, `MOD`, `MONTH`, `NOT`, `NOW`, `OR`, `POW`, `RIGHT`, `ROUND`, `SQRT`, `SUM`, `TEXT`, `TODAY`, `TRIM`, `UPPER`, `VALUE`, `YEAR`，支持跨字段拓扑排序与 `#CYCLE` 检测。
- **视图查询 (`query` / `queryView`)**：支持 11 种筛选操作符（`eq`, `neq`, `contains`, `not_contains`, `gt`, `gte`, `lt`, `lte`, `is_empty`, `is_not_empty`, `in`）、AND/OR 组合条件、多列排序、分组、条件填色（`FillRule`）与选区统计（`computeSelectionStats`）。
- **仪表盘聚合 (`evaluateDashboard`)**：支持 `metric`、`bar`、`horizontal_bar`、`pie`、`line`、`pivot` 6 类组件及 `count` / `sum` / `avg` / `min` / `max` / `checked_pct` 指标。
- **CSV 推类型导入导出**：`Base.fromCsv(csvText)` 自动推断字段类型，`base.toCsv()` 导出包含公式/Lookup 计算结果的 RFC 4180 CSV。

```ts
import { Base, createBaseTools, defaultDashboardWidgets } from "@zseven-w/base-sdk";

const base = Base.fromCsv("Deal,Owner,Amount,Stage\nAcme,Alice,50000,Won\nGlobex,Bob,30000,Open\n", {
  name: "Sales CRM",
  tableName: "Deals",
});

base.apply([
  { op: "addField", field: { name: "Commission", type: "formula", formula: "IF([Stage]=\"Won\", [Amount]*0.1, 0)" } },
]);

const fields = base.getFields();
const widgets = defaultDashboardWidgets(fields);
const dashboard = base.evaluateDashboard(widgets);
const tools = createBaseTools(base);
console.log(base.version, dashboard.length, tools.tools.length);
```
