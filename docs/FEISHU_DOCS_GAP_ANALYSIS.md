# 飞书文档对标调查

## 当前范围与最近进展

用户进一步要求对齐飞书文档、普通电子表格、思维导图、幻灯片、流程图、云盘、知识库和智能纪要。下方原有文档与多维表格调查保留；新增类型不能以文档块或多维表格冒充。各能力组覆盖范围和工作量不同，不能据此计算整体完成率。

2026-11-09 文档页外观：参照飞书公开帮助（标题自动生成左侧目录、分享在右上角、标题旁收藏）与开放平台文档组件配置（目录可显示/折叠、默认宽度），把目录从遮挡顶栏的右侧浮层改为正文左侧吸顶目录并随滚动高亮；块悬停改为「类型图标 + 拖拽点」手柄与块菜单（转换/在下方添加/删除）；斜杠菜单改为基础块图标网格 + 列表；评论和历史面板停靠在顶栏下方、正文让出宽度；收藏星标移到标题旁；行内代码改为中性样式。本轮未在用户登录的飞书中逐像素复核，块菜单仍缺复制、评论、复制链接、颜色与缩进，目录不支持折叠/固定切换，见[截图记录](FEISHU_DOCS_VISUAL_REPORT.md)。

2026-11-07 文档补充：分享面板增加本地生成的二维码和按姓名或邮箱搜索，邀请已有协作者时不会以默认权限覆盖原授权；外部协作者的成员候选不再包含无关工作区成员。Markdown 普通文本、链接、代码及公式往返已修复部分损坏场景，不能完整导出的内容会在下载前提示。仍有以下边界：

- 分享邀请、链接权限与含分项权限设置的文档更新已在写入事务内复核权限和会话；分享读取返回令牌及写入完成后的网络响应仍有撤权窗口。新权限接口以修订号检测并发变化，旧布尔接口仍有兼容限制；升级时须排空旧服务和现有连接，旧服务只能理解保守布尔投影。普通标题和移动更新尚未纳入该事务保护。正文及图片预览已发到浏览器后，界面限制不能防止提取这些数据。
- Markdown 表格单元格、分栏布局、图片和附件等尚不能完整往返；提示并不等同于保真导出。
- 数据库回滚后的协同历史身份校验尚未实现。针对重复操作 ID 和重叠字符区间的修复仍在验证，当前方案存在长历史性能风险，尚未纳入提交。
- 评论与本地通知同事务提交；正文提及仍可能在协同操作确认前产生通知，请求响应丢失后重试也可能产生重复评论。历史跨文档回复删除会安全拒绝，PostgreSQL 删除时使用评论表级锁，跨文档写入可能等待。旧版本服务不理解评论策略，升级时必须排空旧服务和连接。

2026-11-07 多维表格更新：已参照实际飞书空白表格调整主框架、工具栏、网格及字段弹层；新表原子创建“文本”字段、“表格”视图和 5 条空记录。日历支持按日、周、月切换，无日期或无效日期列为未排期；小时级时间轴、起止时间和拖拽并发保护尚未完成。实际飞书还提供多数据表、仪表盘和工作流等能力，当前界面和功能未达到一比一。

- 当前项目把部分 locked 视图作为访问限制；这与飞书用于保护视图配置的锁定功能及飞书高级权限不是同一能力。受限制的非管理者暂不能写入、下载附件、导出 CSV 或接收原始实时事件，页面通过受控轮询刷新。
- 被限制的查询和关联展开按当前用户权限过滤；不支持安全求值的派生字段、关联字段及多选内容的锁定筛选会明确拒绝。CSV、普通字段/记录写入等已将权限复验与写入纳入事务；授权读取和网络发送之间仍有时间窗口，不能宣称权限已严格线性化。
- Base 主读取路径的源表、关联目标及事件头使用同一快照，并在响应前复验权限和可见记录；源表仍受前 1 万条范围限制，关联也有资源上限，超限会报错。筛选查询端点尚未整体迁移到同一数据库快照。
- CSV 导入已恢复，字段与有效记录在授权事务内写入，无效行会报告；响应丢失时结果仍可能不确定，须核对后再操作。PostgreSQL 当前使用过渡性的表级锁，不同 Base 的写入可能相互等待。
- 创建 Base 与回收父节点的竞态已单独处理；普通文档创建、移动及其他树写入尚未整体验证。日历和甘特日期写入已增加服务端旧值比较；实际拖拽尚未在浏览器验收通过。
- 表格视图支持重命名、复制及原子重排，字段重排也校验完整旧顺序。主字段身份已持久化；旧表优先保留原文本标题字段和列顺序，受保护的历史隐藏配置不会被自动展开。旧版服务仍可能绕过部分主字段顺序限制；公式、关联及查找类型的跨表主标题仍未完整支持。单元格和批量写入的未知结果在当前会话中保留待核对，刷新或退出后草稿不会持久保留。
- 收集表需管理员显式选择字段并发布随机链接，可设置必填并关闭；旧数字链接不再匿名开放。匿名人员、关联和附件暂不支持；链接复制的系统剪贴板、重新发布及跨浏览器故障恢复尚未完整验收。
- 多维表格实时同步目前将事件作为授权快照刷新提示，前台定时重取作为最终收敛兜底。Base 主读取路径已使用一致快照取得数据和事件头；按表连续序号与协议版本迁移尚未启用，不等同于完整实时协作。[迁移设计](BASE_EVENT_PROTOCOL_DESIGN.md)记录了后续门禁和验证要求。

2026-11-07 更新：主页的“最近”使用按账号记录的实际访问历史，并保留单独的“最近更新”；全局搜索读取文档当前内容并重新校验权限，收藏、最近访问和层级响应也会过滤撤权后的信息。文件上传与粘贴遇到取消、失败或无法安全插入时保留原文；同步追平时保留尚未解决依赖的本地草稿。这些改进仍不表示已与飞书完整对齐：

- 搜索目前逐篇重建当前内容，设有 10 秒请求超时，无法完成时明确报错；单篇内容的 CPU 重建无法被超时立即中断，需要持久全文索引和规模性能验证。多维表格目前仅搜索标题，结果也不是跨文档的原子快照。
- 侧栏重命名会更新文档元数据，搜索以该名称为准；编辑器中的协同标题块与侧栏名称仍可能不同步。更多菜单可手动检查并复制两份名称，但不会自动恢复；[一致性设计](DOCUMENT_TITLE_CONSISTENCY_DESIGN.md)中的统一写入和历史恢复仍未启用。检查有大小和并发限制，同步解码无法被截止时间强制中断。
- 文档内查找与替换已覆盖可见分栏文字，并按画布顺序导航；标题、表格和公式仍未纳入。分栏评论已支持锚点高亮、重叠计数和面板定位，跨段评论仍不支持。
- 评论面板权限失效时会隐藏旧内容，未发送输入可保存在当前浏览器并在重新验证后恢复；不同账号、文档和标签分别隔离。本机存储为明文，无 Web Locks 时不能安全清除其他标签记录；真实多标签、关闭标签后恢复及授权变化仍需端到端验证。真实浏览器中已用请求拦截验证连续 403 后停止重试及手动恢复。
- 新插入和粘贴的行内公式有独立标识，光标、删除和撤销按公式段处理；历史数据缺少标识时，连续同值公式的数量无法可靠判断。迟到的协作者编辑可能打断公式，真实系统输入法和多人并发仍需验收。普通斜杠命令及提及已按字符 ID 重定位并在操作前复验，但通知可能在协同操作获服务器确认前发出，且真实输入法仍需验收。
- 最近访问最多保留并返回 100 条；当前权限在请求时重新校验，但已打开页面的撤权信息依赖重新请求，不是实时推送。
- 文件不能安全地在已有文字中间自动拆段插入，分栏内也尚不支持粘贴文件；上传成功后若文档并发变化导致插入取消，可能留下未引用的文件对象。
- 协同草稿缺失依赖时会保留并提示下载备份，但无法自动恢复已被服务端回收的依赖；数据库回滚造成不同历史复用序号的风险仍需协议级解决。

2026-11-06 本轮围绕文档可靠性推进：阅读模式的有权限用户可评论并对同段文字划词；历史版本只读视图补充了常用块渲染；公式、流程图等斜杠命令不再直接删除原段落；链接加入授权与直接邀请分开，关闭链接后旧链接失效；协同连接会重新检查文档权限和原会话。上述能力仍需与飞书逐项对照，且部分实现有明确边界：

- 文本中间插入公式等原子块暂不自动拆段，会保留原文及输入草稿并提示；跨段划词评论也尚不支持。
- 分栏已支持各栏文本输入、换行、格式和撤销；为保护协作者的迟到编辑，目前不支持安全删除栏，跨栏输入、栏内块类型及斜杠插入仍待实现。普通跨块输入法组合目前保留草稿并提示，尚未达到飞书的直接替换体验。
- 对被划词评论覆盖的文字执行替换并撤销后，原文字会恢复，但原字符 ID 已变化，评论高亮可能消失；评论面板中的引用仍保留，锚点恢复机制待补齐。
- 撤销新插入的原子块时为保护晚到的协作者内容可能留下空块；原子块的并发属性撤销仍需进一步验证。
- 协同连接的权限、会话检查与实际持久化或网络发送之间仍有竞态；逐帧查询的多人房间性能尚无基准。
- 数据库回滚后若服务器复用已见过的序号，客户端可能把不同历史误认为重放；需要协议层历史标识和保留旧副本的恢复流程。既往已推进的错误 GC 水位无法自动回退；不支持 Web Locks 的浏览器仅能导出旧账号草稿，不能自动认领恢复。
- 普通业务 API 返回 401 后尚未统一触发顶层会话重新验证；浏览器同时不支持跨标签广播与存储事件时，其他标签无法主动收到账号切换通知。
- 旧版本将链接加入和直接邀请混存，迁移不能识别旧授权来源，需要管理员审查；已经下载或缓存在客户端的文件无法撤回。
- 创建副本会校验目标空间和附件，并为附件创建独立文件 ID；当前最多处理 1000 个不同的可见附件，附件预检总时限 60 秒。底层对象键仍被源文档和副本共享，未来回收对象时必须检查所有引用。
- 版本还原会在提交时重新核验文档序号、编辑权限和会话；并发变化或格式无法保真时返回冲突且不提交部分修改。还原完成后才到达已删除块的离线编辑仍可能被隐藏，数据库死锁会回滚并提示重试，这些边界仍未完全对齐。
- 匿名分享可展示文档中引用的图片及附件，并按当前链接设置检查访问；页面在前台定期刷新，链接失效或改为需登录时会隐藏旧正文。防下载时允许图片预览，但浏览器能读取预览图片字节，因此这不是完整的防泄漏机制。文件访问目前需要重建文档状态，长文和多图片的性能有待评估；请求鉴权与发送之间仍非严格线性化。
- 文档内查找与替换已支持正文及分栏文本的匹配、高亮、导航及撤销；标题、表格、公式与大规模高密度替换仍未覆盖或受限。修订模式、完整分栏操作、Word/PDF 格式保真及模板/分享能力仍待完成；历史版本并发还原与真实双端协作尚需端到端验证。

# 2026-11-08：复核发现的风险

- 云盘已支持普通文件、批量文件和文件夹上传，以及文本及图片预览、下载、分享和回收恢复。支持原生目录读取的安全环境可保留空文件夹，兼容选择器仍无法读取空文件夹；断点续传、文件版本历史和匿名分享仍未完成。上线需排空旧服务并刷新旧客户端；不确定的数据库写入结果可能留下待清理对象。
- 云盘“修改者”覆盖云文档协同操作、历史恢复、标题、封面、图标及部分移动操作；其他类型、历史数据和未覆盖写入显示未知。迁移 0042 增加修订号及操作日志触发器，未覆盖写入会使旧归属失效；逐操作触发器的高并发性能尚未基准测试。普通文档标题、移动及协同操作写入已在持久化时复核原会话和权限；旧服务仍使用旧路径，上线需先排空旧服务。协同输出帧的检查与实际发送之间仍存在竞态，历史代际门禁也未完成。
- 协同客户端和服务端的首次 v2 协商死锁已通过 URL 能力声明修复，并验证新旧连接及表格文档首连。数据库恢复仍需外部 bump epoch；活跃房间跨代际隔离和追加写入的代际原子门禁未完成，回滚防护不应视为已完成。
- 文档复制与源附件删除的并发丢失已通过事务内锁定源附件修复：隔离 PostgreSQL 测试实际观察到删除等待、复制提交后副本仍可读取对象；删除先完成时复制会失败。所有服务实例均需升级后才能依赖该保护，测试不涵盖数据库外直接修改附件引用或对象存储。
