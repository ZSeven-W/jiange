# Security Policy / 安全策略

## Supported Versions / 支持版本

| Version | Supported | Notes |
| --- | --- | --- |
| `0.2.x` / `main` | ✅ Yes | Active security & bug fixes |
| `< 0.2.0` | ❌ No | Please upgrade to the latest release |

## Reporting a Vulnerability / 报告安全漏洞

Please **do not** disclose security vulnerabilities in public GitHub Issues or Discussions.

请**不要**在公开的 GitHub Issue 或 Discussion 中披露潜在安全漏洞。

Report vulnerabilities privately through GitHub Security Advisories:

- **Private Advisory**: <https://github.com/ZSeven-W/jiange/security/advisories/new>

When reporting, please include:
1. Affected component (`apps/web`, `server/`, `packages/*`, `sdk/*`, or `cli/`)
2. Reproduction steps or proof-of-concept
3. Impact assessment (e.g., Auth/SAML/OIDC/SCIM, Passkeys, DLP, RBAC, XSS, CRDT sync)

We aim to acknowledge reports within **48 hours** and coordinate remediation before public disclosure.
