# Changelog — jiange-cli / jiange-mcp (Go)

## [0.2.0] - 2026-11-21

### Added & Changed
- Initial release of zero-dependency Go 1.23 single-binary CLI and JSON-RPC 2.0 MCP server (`stdio` + Streamable HTTP).
- Supports local `.xlsx`, `.docx`, `.pptx`, `.mmd`, `.xmind`, `.csv`, and `.json` files plus remote Jiange backend server access (`jiange remote`).
- Achieved 100.0% Go statement coverage with `-race`.
