# 功能一览

## 文档
- 自研块编辑器：标题/列表/待办/引用/代码块（语言选择、复制）/分割线/高亮块/表格块/图片/附件，Markdown 快捷输入，斜杠菜单（拼音匹配），IME 兼容
- 实时协同（Fugue 序列 CRDT + Peritext marks），在线光标与头像
- 评论：划词锚定字符 ID、回复、@人（成员补全）、解决/重开；块右侧气泡角标
- 历史版本：手动 + 自动快照，只读预览，还原（正向操作，不改写历史）
- Markdown 导入/导出；版本对比数据可用
- 通知中心：@提及/回复/解决，未读红点，点击跳转
- 分享：三级角色（view/edit/manage，可继承）、链接分享（登录用户 3 级 / 任何人只读）、防复制下载 + 水印、创建副本

## 多维表格
- 视图：表格（虚拟滚动 1 万行）、看板、画册、日历、甘特（MVP）、表单（公开收集）
- 字段：文本/数字/单选(配色)/多选/复选框/日期/人员/附件/URL/电话/邮箱/评分/创建人/创建时间/修改时间/公式/关联/查找引用
- 公式：自研 parser+evaluator（35 函数、依赖图、环检测），Go 校验同一语法
- 视图配置：筛选（且/或多条件，服务端 SQL 编译防注入）、多级排序、分组、隐藏字段、锁定（行级谓词 + 列剔除/写保护）
- 单元格：方向键/Tab/Enter/F2 导航、TSV 复制粘贴（与 Excel 互通）、列统计、列宽拖拽、字段拖拽排序、行详情抽屉
- 实时协同：事件流广播，断线重连补发
- CSV 导入（类型推断 + 逐行错误报告）/导出

## 平台
- 邮箱注册登录、回收站、全文搜索（标题 + 正文）、收藏、模板（创建副本）
- 附件走 S3/MinIO（SigV4 自研）
