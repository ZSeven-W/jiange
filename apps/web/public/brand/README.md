# Jiange 品牌资源

- `jiange-mark.svg`：独立图形标志，透明背景。
- `jiange-wordmark.svg`：深色文字标志，适用于浅色背景。
- `jiange-wordmark-light.svg`：浅色文字标志，适用于深色背景。
- `jiange-lockup.svg` / `jiange-lockup-light.svg`：图形与文字组合版。
- 同名 `.png` 为透明背景导出：图形 1024×1024、字标 3000×980、组合版 1922×512。

上述 SVG 使用路径绘制，缩放时不依赖用户本机字体。字标轮廓基于 Nunito（含单层 a 变体），按 [SIL Open Font License 1.1](NUNITO-OFL.txt) 使用；图形依据项目中的 `jiange-logo-concept-v1.png` 重新绘制。网页登录、侧栏、公开文档和表单共用这些资源，网站图标使用独立图形标志。
